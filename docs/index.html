Features

Everything a small business needs, in one place

From the moment someone clocks in to the salary slip at the end of the month.

Simple attendance screen

A large live clock, a searchable employee list and one clear action. Clocking takes three steps.

Reliable clocking

Uses the server's time, blocks double clock-ins, and never claims success until the record is saved.

Flexible shifts

Day, overnight and 24-hour shifts, with Day 1 / Day 2 selection, grace periods, holidays and leave.

Accurate records

Late arrivals, early departures, overtime and missing clock-outs are worked out automatically.

Overtime approval

Managers add overtime hours with a reason. Only approved hours count towards pay.

Salary slips

Basic salary, allowances, deductions and overtime, with a printable A5 slip that lists every line.

Reports and Excel

Eleven reports with filters, and one button to export them all into a single Excel workbook.

Roles for everyone

Super Admin, Admin, Manager, Attendance Manager and Viewer, each seeing only what they need.

Backups built in

One-click backup and restore. A safety copy is saved before every restore, purge or reset.

How it works

Three steps at the attendance screen

No login for employees, so it works on a shared computer at the entrance.

Select your name

Open the dropdown and type your name or employee ID to find yourself.

Check your status

See your shift and whether you are clocked in, clocked out or not yet scheduled.

Press the button

The available action lights up. A confirmation shows your name and the exact time recorded.

Access

The right access for every role

Permissions are checked by the server, not just hidden on screen. Pay details stay with the people allowed to see them.

Get started

Up and running in minutes

On Windows, one double-click installs anything that is missing and opens Timora in your browser.

  1. Get the codeClone the repository, or download the ZIP from GitHub and extract it.
  2. Double-click start-timora.batIt installs Python and the required components if needed. The first start takes a few minutes.
  3. Log in and set upSet your timezone and company details, then add shifts and employees.
  4. Keep the window openTimora runs while that window is open. Closing it stops Timora.
# Get the code
git clone https://github.com/JayashankaAnushan19/timora_attendence_shift_clockIOut_mng_system.git

# Already have it? Get the latest version
git pull

# Then double-click start-timora.bat
First login: username admin, password admin@123. You will be asked to choose a new password straight away.
